## Description

bugdesk and Tables each built the same things on FlexDesk's CSS: a bottom-panel tab strip
(`../bugdesk/ui/js/ticketdesk/pages.js:2306-2390`; `../Tables/web/js/bottom_panel.js:24-195`, without badges) and a
notification surface (bugdesk's Alerts tab and log, `../bugdesk/ui/js/ticketdesk/alerts.js`; Tables' bell,
`../Tables/web/js/shell/notification_bell.js`). The Tables product owner, 2026-10-14: *"In case we have re-usable
components between bugdesk and tables, we should directly implement them and provide them via ../FlexDesk in both
solutions."* Tables EPIC-0292 and bugdesk STORY-0031 consume this.

FlexDesk today has `.twm-bp*` CSS but no tab-host JS, a NotificationCenter with an in-memory history of 50, and a
NotificationHistory bell whose mount point is hard-coded and whose "unread" is a seen-count delta. All additive:
an embedder that uses none of it sees no change. bugdesk's alert RULES stay in bugdesk.

## Acceptance criteria

- [ ] STORY-0018: a bottom-panel tab host with badges
- [ ] STORY-0019: an alert log and an Alerts pane with history, filters and read state
- [ ] STORY-0020: the bell shows real unread state, mounts anywhere and opens the Alerts tab
- [ ] Used by both bugdesk (bugdesk STORY-0031) and Tables (Tables EPIC-0292)
