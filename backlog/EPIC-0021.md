## Description

`@flexdesk/tiles` has the dashboard grid (TileGrid, TileBase, the widget registry, layout persistence) and
`@flexdesk/charts` has the trace builders and the Plotly wrapper, but nothing joins the two: every embedder that
wants a chart on a dashboard writes its own TileBase subclass. BugDesk is about to (BugDesk EPIC-0033 Dashboards,
`../bugdesk/backlog/EPIC-0033.md`). Ship generic chart and KPI tiles here so it doesn't, and so Tables can use the
same ones.

## Acceptance criteria

- [ ] An embedder can put a line/bar/area/pie/donut/histogram chart or a KPI number on a TileGrid by registering FlexDesk's tiles and feeding them data, without subclassing TileBase (STORY-0022)
