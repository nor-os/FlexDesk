## Description

`@flexdesk/host` has one native adapter, pywebview's. BugDesk is becoming a
desktop app in a Photino.NET window (BugDesk EPIC-0021,
`../bugdesk/backlog/EPIC-0021.md`), and EcoSim is to move onto the same bridge
later. Each native host gets an adapter here, so an app picks its host and the
rest of FlexDesk (save dialogs, window chrome, state) works unchanged.

## Acceptance criteria

- [ ] A FlexDesk app running in a Photino window gets the host port's window, dialogs and state capabilities from FlexDesk's own adapter (STORY-0015)
