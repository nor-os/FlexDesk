## Description

An application moving its whole chrome onto createShell needs shell capabilities every desktop app otherwise re-implements: a menu bar, control over built-in key chords, kinds that may exist once, a navigator driven from outside, panels offered per kind, panel sizes that survive, a collapsible inspector section stack, tile actions that change after mount, storage keys and theme names the embedder chooses, and no reads of ambient globals. Each is opt-in and changes nothing for embedders that do not use it.

Filed from the EcoSim -> FlexDesk 0.16 migration analysis (2026-10-17).
