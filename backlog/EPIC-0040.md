## Description

Configuration dialogs, settings pages and editors keep needing controls FlexDesk does not yet ship: richer openForm fields, a switch, a colour field, a slider with number box and reset, a tag input, a wizard, a public tab strip, separators in ActionDropdown and a settings view over the store FlexDesk already owns. Each is domain-free and themed on tokens.

Filed from the EcoSim -> FlexDesk 0.16 migration analysis (2026-10-17).
