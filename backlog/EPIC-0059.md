## Description

@flexdesk/charts owns the plot_config model, but only PlotPopoutWindow can draw it, nothing can edit it, and its derived-series overlay is a fixed backend call. Exporting the renderer, an editor and an injectable transform option lets any embedder show the same figure in a tile, an inline view and the window.

Filed from the EcoSim -> FlexDesk 0.16 migration analysis (2026-10-17).
