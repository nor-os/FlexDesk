## Description

Why: an application should be able to build a typed dataflow or diagram modeler on FlexDesk alone. The reference case is the node modeler of the first EcoSim version (`../EcoSim_legacy/EcoSim/html/js_new/nodes/`, `node_addons/`, `workspace/history_service.js`, `ui/components/node_type_picker.js`), which EcoSim retired in favour of notebooks. norman wants its abilities kept as a generic FlexDesk capability (2026-10-17), so that bringing a modeler back into any app needs nothing new from the library.

This EXTENDS the existing canvas editor (`src/flow/canvas_editor/`, `src/flow/kit/`, `src/canvas/`); it does not add a second modeler. Everything EcoSim-specific in the legacy code (DSL collectors, stocks/flows/Godley, namespaces, backend function docs, simulation feed) is left out or becomes a host hook.

Owner decisions (norman, 2026-10-17):
- Ships in 0.17.0 together with the migration work (STORY-0069 lists these stories).
- Options only: every capability is an option on createCanvasEditor or a catalogue type key. No preset.
- Undo stays FlowHistory's whole snapshots; STORY-0076 carries a size threshold.
- Groups are flat, one group per node, no nesting.
- FlexDesk's default keymap stays (no Backspace delete).

Additive public API changes to list in the 0.17.0 changelog: CANVAS_ACTIONS gains the new action ids; onSelect can report {kind: 'many', ids}; normalise()/getGraph() may carry optional groups, notes, collapsed and size keys (absent unless used, so existing graphs stay byte-identical).

Stories: STORY-0074 (node bodies) first; then STORY-0075, 0076, 0079, 0081, 0082, 0083 in parallel; STORY-0077 and 0078 after 0076; STORY-0080 any time; STORY-0084 (demo and probe) last.

Related: EPIC-0005 (canvas follow-ups for Tables), STORY-0065 (lane duplicate naming), STORY-0007 (Landscape/Topology uses the same viewport and badge hooks).

## Acceptance criteria

- [ ] An app can build a typed node modeler (custom node bodies, data connections, multi-select, clipboard, groups and notes, layered layout, styled edges, viewport persistence through the host, live values) using only createCanvasEditor options and catalogue types, shown by demo/flow_modeler.html (STORY-0084)
- [ ] Tables' existing canvas flows behave and serialise exactly as before: the full suite is green and no existing test changed its expectations
- [ ] Every story under this epic is done
