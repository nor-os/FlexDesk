## Description

The product owner, 2026-10-07: *"yes, it is flexdesk"*. Tables' Sources Landscape and Administration ▸ Topology
become FlexDesk components. A schematic component or the canvas kernel is a design call.

Behaviours the component must make possible (Tables supplies the domain): lamps per node, Fit and zoom on the
slider's stops remembered per person, "+K more" side lists, bands (Tables bands by organization), a node that opens
its page in one press, and a node's managed window (one per node; a second press raises it). Domain-neutral (the
vocabulary gate), additive and off by default; the release number from the integrator.
