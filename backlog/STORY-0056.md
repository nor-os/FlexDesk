## Description

Takes entries {id, level, label}, optional hierarchical numbering, level indentation with max depth, onSelect(id), scroll-spy over a given scroll container and target resolver with configurable rootMargin, tracking suppressed during a click-started scroll (resume on scrollend with timeout fallback), setEntries/refresh/setActive/getActive/onActiveChange/dispose.

Related EcoSim records: EcoSim STORY-0089 (`../EcoSim/backlog/STORY-0089.md`).

Filed from the EcoSim -> FlexDesk 0.16 migration analysis (2026-10-17).

## Acceptance criteria

- [x] Entries with levels 1,2,2,1 are numbered 1, 1.1, 1.2, 2
- [x] Scrolling the container marks the topmost visible section active
- [x] Clicking an entry keeps it active during the resulting scroll
- [x] An entry whose target cannot be resolved is listed but never marked active
- [x] dispose() disconnects the observer and clears timers

### 2026-10-17T23:50Z · norman_agent (status: in-progress -> review)

Built `createDocumentOutline(host, config)` / `DocumentOutline` in `@flexdesk/widgets` (`src/ui/components/document_outline.js`). Entries `{id, level, label}`, labels drawn as plain text; optional hierarchical numbering where a skipped level counts as one step deeper (1,3,3,2 -> 1, 1.1, 1.2, 1.3); entries deeper than `maxDepth` (default 3) are listed, indented and numbered at `maxDepth` (clamped, not hidden, as EcoSim's paper TOC does). A click calls `onSelect(id, entry)` and scrolls the target into view smoothly; `scrollOnSelect: false` leaves the scrolling to `onSelect`. Scroll-spy is an IntersectionObserver rooted at the scroll container with a configurable `rootMargin` (default `'0px 0px -70% 0px'`); targets come from `resolveTarget` (default: the element with the entry's id in the container); the first listed in-view section is active, and with none in view the last one stays. A click-started scroll pauses tracking until `scrollend` or `scrollEndTimeout` (1000 ms). An unresolved entry is listed but never watched or active, and `setActive` refuses it (returns false). Also `setEntries`, `refresh`, `getActive`, `onActiveChange` (returns an unsubscribe), `dispose`, and an empty state ('No headings'). CSS block "DOCUMENT OUTLINE (0.17.0)" in `css/base.css` and `css/flexdesk.css`, after TOGGLE and before FLOW · KIT; README section "A document outline: `createDocumentOutline` (0.17.0)". No existing public API changed.

Ticked all five criteria: numbering 1,2,2,1 -> 1, 1.1, 1.2, 2; scrolling marks the topmost visible section active; a clicked entry stays active during the resulting scroll; an unresolved entry is listed but never active; dispose() disconnects the observer and clears timers. Each is covered by `tests/document_outline.test.mjs` (§1–§7).
