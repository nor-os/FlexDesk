## Description

BugDesk opens the outline editor (`createOutlineEditor`) in a modal
ManagedWindow. Clicking "Add a step" opens the step picker BEHIND that window,
so it cannot be used.

`.twm-flow-popover` (the step picker, the value picker and the step menus,
`src/flow/kit/dom.js` `openPopover`) and `.twm-flow-outline__ghost` (the
grip drag) use `z-index: var(--z-popover)`, 200. Managed windows stack from
6000 to 6999 (`managed_window.js` BASE/MAX_Z_INDEX). The context menu already
sits above them (10050). Any flow editor hosted in a window has the bug.

Seen from BugDesk STORY-0028 (`../bugdesk/backlog/STORY-0028.md`).
