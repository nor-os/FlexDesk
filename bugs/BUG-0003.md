## Description

Defect 1: the twm- class rename also rewrote allow-list strings in src/core/state_guard_config.js:19, 60, 62, 82, 86 ('twm-has-tooltip', 'twm-collapsible-header/-content', 'twm-latex-tooltip', 'twm-node-name'); no element uses them, and camelCase entries never match because keys are kebab-cased (state_guard.js:181-184, 249).
Defect 2: unlisted keys written outside executeWithBypass: tile_renderer.js:365 data-twm-tabs, tooltip_service.js:354 data-latex-tooltip, modal.js:206 data-twm-required, modal.js:500/516 data-action-idx/-value, bottom_panel_tabs.js:86/106 data-pane.

## Steps to reproduce
1. `const guard = new StateGuardService({eventBus, logger, config: {...DEFAULT_STATE_GUARD_CONFIG, mode: 'strict'}})`.
2. Call createShell(), open showChoiceDialog, hide a required openForm row, or set a LaTeX tooltip.

## Expected
FlexDesk's own widgets pass the guard FlexDesk ships.

## Actual
Strict: 'StateGuard blocked dataset:set on "data-twm-tabs"' is thrown from TileRenderer construction; dialogs fail to build. Warn: a violation per dialog, shell build, tab and tooltip.
