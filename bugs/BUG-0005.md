## Description

#resolveModuleFromStack (src/core/state_guard.js:277) matches only /(js_new\/[^)\s]+)/; dist chunk frames never match, so moduleKey is null and #isAllowedForModule (:218) returns false. DEFAULT_OVERRIDES (state_guard_config.js:205-213) ships an override for a file that is not part of FlexDesk, and DEFAULT_MODE reads an application-named debug global.

## Steps to reproduce
1. In an app under src/app/, construct a strict StateGuardService and allow('src/app/my_widget.js', ['data-foo']).
2. From my_widget.js call el.setAttribute('data-foo', 'x').

## Expected
The module override allows it.

## Actual
Throws 'StateGuard blocked setAttribute on "data-foo" from unknown module'; library writes are attributed to the first matching frame up the stack. Fix direction: make the frame matcher configurable and remove the app-specific default override and global.
