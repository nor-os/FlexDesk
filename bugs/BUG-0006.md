## Description

src/ui/utils/overlay_scrollbar.js:400 getElementById('twm-fixed-200') returns null; the initial pass (:401-403) is skipped and the observer falls back to document.body (:427). The function takes no root parameter. tooltip_service.js:285/297 skip '.panel.twm-fixed-200 .node.template', a selector no FlexDesk element matches.

## Steps to reproduce
1. Render visible .twm-collapsible-content elements in a sidebar.
2. Call installCollapsibleScrollbars().

## Expected
Already-visible sections get overlay bars, scoped to a caller root.

## Actual
No bars until a class toggles; every class mutation in the document runs the callback.

Related EcoSim records: EcoSim STORY-0047 (`../EcoSim/backlog/STORY-0047.md`).

Filed from the EcoSim -> FlexDesk 0.16 migration analysis (2026-10-17).
