## Description

openConfirm (src/ui/components/modal.js:318-328) writes message and labels into innerHTML; showDeleteConfirmDialog/showCloseConfirmDialog (confirm_dialog.js:62-71, 86-93) concatenate itemName raw.

## Steps to reproduce
1. showDeleteConfirmDialog({itemName: '<img src=x onerror=alert(1)>', itemType: 'flow'}).

## Expected
The name is shown literally.

## Actual
Markup renders and the handler runs; an unclosed '<' swallows the rest of the message.
