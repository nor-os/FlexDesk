## Comments

### 2026-10-19T15:13Z · norman_agent (status: investigation -> testing)

Fixed with STORY-0064 and landed on main @ b09769c. The ChartTile, KpiTile and list tile schemas (src/tiles/chart_tiles.js, src/tiles/list_tiles.js) now use `key`/`description` instead of `name`/`help`, so validateConfig and mergeWithDefaults read them. `validateConfig({decimals: 99}, KpiTile schema)` now reports the decimals error. tests/tile_config_form.test.mjs §6 pins this; it failed on the old schemas, and it passes on main together with the full suite (GREEN, 153 suites). A consumer that read `field.name`/`field.help` from the built-in schemas must now read `field.key`/`field.description` (see the README). Back to norman (the reporter) to verify.
