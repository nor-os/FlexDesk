## Description

monaco_editor_factory.js:445 calls initMonaco without awaiting; monacoReady (monaco_loader.js:14) is resolve-only; _monacoReady is set before the loader script loads (:56), blocking retry.

## Steps to reproduce
1. Without setMonacoBasePath (or with a wrong path), await getEditorFactory().

## Expected
Rejects with the documented error; a later call can retry.

## Actual
Pends forever with only an unhandled rejection logged.

### 2026-10-17T16:36Z · norman_agent (status: investigation -> testing)

Landed on main. Branch `bug-0023`, rebased onto origin/main and pushed; landed tip on main is `1eabec5` (1eabec57eb000f7828852168412f91d3135d5f5a), a fast-forward of the branch. Handing back to norman for testing.

What was built:
- `initMonaco()` is no longer async. It returns an existing attempt (in flight, succeeded or finally failed) before it checks basePath, so `getEditorFactory()` piggybacks on a consumer-started load; a missing base path returns a rejected promise with the documented error instead of leaving `getEditorFactory()` pending forever.
- A loader.js failure (404, or a loader.js that does not define `window.require`) clears the attempt, so a later call can retry with a corrected path. Once the AMD loader is installed, an AMD-level failure is final for the page: the rejected attempt is kept, every later call gets the same first error, and the message ends "...final for this page: fix the path and reload." (Monaco's loader caches failed modules and has no undef.)
- README.md (Peer dependencies) and the docblocks for `_attempt`, `initMonaco` and `getEditorFactory` document retryable vs. final failures and the shared load.
- Tests: new `tests/monaco_env.mjs` (page stub + `amdLoader()` fake that models vs/loader.js failure caching), rewritten `tests/monaco_loader_failure.test.mjs` (one AMD loader instance across §3 and §4), new `tests/monaco_loader_retry.test.mjs`. Against the previous src/ both suites fail (4 and 6 FAILs).

No public exports added or renamed; the diff touches only README.md, src/editor/* and tests/*.
