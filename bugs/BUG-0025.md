## Description

Classes .editor-pane*, .split-pane*, .nb-search-bar* (editor_pane.js:89,124; split_pane_container.js:56,61,119; notebook_search.js:70,106) have no rule in any shipped stylesheet; the README says flexdesk.css is the whole contract.

## Steps to reproduce
1. With only FlexDesk CSS, mount a split SplitPaneContainer and open the search bar.

## Expected
Side-by-side panes, a draggable divider, a styled search bar.

## Actual
Panes stack, the divider has zero width and cannot be grabbed, the search bar is unstyled.

Related EcoSim records: EcoSim STORY-0081 (`../EcoSim/backlog/STORY-0081.md`).

Filed from the EcoSim -> FlexDesk 0.16 migration analysis (2026-10-17).
