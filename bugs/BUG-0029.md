## Description

Found while fixing BUG-0003 (branch `bug-0003`). `DEFAULT_STATE_GUARD_CONFIG.allowedDatasetKeys` in src/core/state_guard_config.js still holds groups of keys that belong to one embedding application, not to FlexDesk: "Simulation/scenario state keys" (scenario-id, run-id, run-state, ...), "Scenario editor keys" (mirror-input-bound, mirror-change-bound, override-type, ...), "Calibration page keys" (info-for, column) and "DSL generator keys" (dsl-state, dsl-section-registered, dsl-scrollbars-installed, dsl-tabs-bound, dsl-controls-bound). No widget under src/ writes them.

BUG-0003 left them alone on purpose: taking them out of the defaults is a breaking change for any embedder that relies on them being allowed, and it is outside BUG-0003's scope. The BUG-0003 README section now says the list also carries keys FlexDesk itself does not write.

## Decision needed

Owner to decide: (a) remove the application keys from the defaults (breaking; embedders add their own keys, release note required), (b) move them to a separately exported, generically named preset, or (c) keep them as they are. Until then, nothing changes.
