## Description

package.json maps `./css` and `./css/reset` (BUG-0027) to `dist/`, but
`./css/tokens` to the source `./css/tokens.css`. The README's Styling section
names `dist/tokens.css` as the contract file. The two are byte-identical in a
release, because dist/ is rebuilt only in the release commit, but on a working
checkout (or a git dependency) they can differ, so `flexdesk/css/tokens` does
not serve the file the contract documents.

Found while fixing BUG-0027; the README on branch bug-0027 now states the real
mapping (`flexdesk/css/tokens` -> `css/tokens.css`) and tests/css_exports.test.mjs
pins it, so fixing this means changing the exports target, the README row and
that test together. Repointing an existing public specifier is the owner's call.

## Steps to reproduce
1. `node -e "console.log(require.resolve('flexdesk/css/tokens'))"` from the package root.

## Expected
Resolves to dist/tokens.css, like the other two contract stylesheets.

## Actual
Resolves to css/tokens.css.
