## Description

`src/charts/plot_popout_window.js:45` defaults `streamEvents` to `{delta: 'streaming:delta', complete: 'streaming:complete'}`. Those are EcoSim's bus event names, so a FlexDesk default carries application vocabulary, and a popout in any other app subscribes to events that app never emits. Found while handing back BUG-0022 (2026-10-19); norman decided the defaults go.

## Steps to reproduce

1. Construct a PlotPopoutWindow with a bus and without `streamEvents`.
2. Inspect its subscriptions: it listens on 'streaming:delta' and 'streaming:complete'.

## Expected

No default stream event names. The popout subscribes to stream events only when the embedder passes `streamEvents`; without them it updates through `refreshEvent` and explicit calls only. The README's 0.17.0 section says so, and a regression test fails on today's main.
