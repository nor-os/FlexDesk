## Description

Found while releasing 0.17.0 (STORY-0069): package.json's exports map gives each entry a `development` condition pointing at the root entry files (`./core.js`, `./host.js`, `./wm.js`, ...). Those files are not in "files", so the published package does not contain them. Present before 0.17.0 too.

## Steps to reproduce

1. `npm install flexdesk@0.17.0` in an empty directory.
2. Resolve `flexdesk/core` with the `development` condition (e.g. `node --conditions=development -e "import('flexdesk/core')"`).

## Expected

The import resolves to a file the package ships. Either the root entry files are shipped, or the `development` condition is removed from the exports map; a test checks that every exports-map target exists in `npm pack --dry-run`'s file list. Ships in 0.17.1 (STORY-0097).
