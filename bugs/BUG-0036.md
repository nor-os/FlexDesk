## Description

Found by EcoSim STORY-0047 (`../EcoSim/backlog/STORY-0047.md`) on FlexDesk 0.17.3 in a non-maximized window: WindowChromeController's fixed 6px .twm-resize-handle strips (z-index 9999) sit where the bar goes, and barCovered() then sets the bar to display:none. norman decided on 2026-10-23 that the FlexDesk gaps EcoSim's post-cutover stories found are fixed in FlexDesk first and released as 0.17.4.

## Steps to reproduce

1. In a non-maximized window with window chrome, scroll a pane flush against the right window edge.
2. Watch its overlay scrollbar.

## Expected

The overlay bar shows: barCovered() ignores .twm-resize-handle elements. It still hides a bar that a real overlay covers. A regression test fails on today's main. Documented in a README section headed "(0.17.4)".
