## Description

Found by EcoSim STORY-0071 (`../EcoSim/backlog/STORY-0071.md`) on FlexDesk 0.17.4 (also on main a7ec89b). `DataSeriesPlotWindow.createDefaultConfig` is a static method that calls `this.classifyHeader(h)` (src/charts/data_series_plot_window.js:703). In a static method `this` is the class, and `classifyHeader` is an instance property set in the constructor (line 69, defaulting to `defaultClassifyHeader`). So opening any data series that has no saved plot config throws `TypeError: this.classifyHeader is not a function`.

## Steps to reproduce

1. Open a DataSeriesPlotWindow on a series with a numeric time column and no saved plot config.

## Expected

The default config is built with the window's header classifier (the one passed as `classifyHeader`, or `defaultClassifyHeader`), so the X axis defaults to the time column, and nothing throws. A regression test fails on today's main. Documented in a section headed "(0.17.5)" in the docs page for data series plots (docs/components/).

Fixed on main and released in 0.17.5 (on npm). 9c37202: DataSeriesPlotWindow.createDefaultConfig(headers, numericColumns, classifyHeader = defaultClassifyHeader) takes the classifier as an optional third parameter, and the window passes its own classifyHeader, so a series with no saved plot config opens with its time column on X instead of throwing. Regression test tests/data_series_plot_default_config.test.mjs fails on the old main with "this.classifyHeader is not a function". Documented in docs/components/charts.md, "A data series with no saved plot config opens (0.17.5)" (9c59b16). Independently reviewed and approved. Two minor notes were left as they are: one test call is not wrapped, so a failure crashes before the summary line but still exits 1; the docs snippet leaves out datasetName.
