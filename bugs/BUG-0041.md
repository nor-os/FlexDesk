## Description

The plot config body appends is3D ? section('Z axis', …) : null (dist/charts.js around line 991, source in src/ charts' plot config). Element.append(null) inserts the text 'null', so every 2D plot's config shows a stray 'null' line.

## Steps to reproduce

1) Open a PlotConfig editor (createPlotConfigEditor or the tile/plot-cell config) for a 2D plot. 2) Scroll to the end of the Y axes section.

## Expected

No stray text: the Reference lines heading follows the Y axes section. A regression test fails without the fix.
