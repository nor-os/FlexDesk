## Description

FlexDesk's plot config offers Linear, Step and Cubic spline. EcoSim projects save interpolation 'auto' (getting-started 34 times, world3 92 times); the old EcoSim editor offered Auto, Linear, Step and Cubic Spline. Every such plot's editor shows 'auto (not found)'.

## Steps to reproduce

1) Open the plot config of a plot whose config has interpolation: 'auto'. 2) Look at Display > Interpolation.

## Expected

'auto' is a supported interpolation value: the select offers it, the chart renders it as it does today, and a config saved with 'auto' keeps it unchanged (data parity for embedders). If the chart has no 'auto' behaviour, define it and document it. A regression test fails without the fix.
