## Description

norman, 2026-10-26 (EcoSim's Document Settings form): "input fields look too small." In a `{ row: [...] }` every field is `flex: 1 1 0`, an equal share of the row, but the first one's share also holds the form's 130px label column while the others' labels are only as wide as their text. With four fields in a 640px form the first input is ~15px wide ("Top (cm)"), and with three ~55px ("Header Left"). `_estimateWidth` gives any form with a row 640px, however many fields the row has.

## Steps to reproduce

1. openForm with `{ row: [a, b, c, d] }` of number fields (EcoSim: Paper > Document Settings).

## Expected

The inputs of a row are equally wide and usable.

## Actual

The first input is a sliver; the others are wider.

## Acceptance criteria

- [x] In a row every input gets the same width: the row's free space is shared equally after the labels (the first's 130px column, the others' own width).
- [x] A form whose widest row has three or more fields opens wide enough for inputs of a usable width (clamped to the window); forms without such rows open as before.
- [x] The narrow-form stacking (container query under 360px) still works. Tests in FlexDesk's suite; docs.
