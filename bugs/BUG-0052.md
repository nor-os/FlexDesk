## Description

norman, 2026-10-26 (EcoSim, screenshot of a plot's config with three series): each series shows the variable box, the label, the colour swatch with a wide hex field, the width and the line style crammed into one wrapped line (`.twm-plot-config__series-main`), then a stack-group input with an x, then the embedder's "Scenario" select with its hint and the "Overlay" select, with inconsistent label columns and widths. The row is `renderPlotConfigEditor` -> `seriesRow` (src/charts). An embedder's `extraSeriesFields` are drawn by the embedder and cannot use the editor's internal `field(label, control)` layout.

## Expected

Each series is one tidy block: a header line (variable, label, remove) and aligned fields on one label column (colour, width, dash, stack group, overlay, and the embedder's extra fields), readable at the editor's usual widths (a ~600px config window and down to 360px).

## Acceptance criteria

- [x] seriesRow lays out a header line plus label-column fields on FlexDesk's form layout; nothing overflows at 360px+; the colour is ColorField (swatch + compact hex).
- [x] `extraSeriesFields` can be drawn on the same layout (e.g. specs FlexDesk renders, or the `field(label, control)` helper passed to the embedder) — additive, the current form keeps working.
- [x] The config objects the editor reads and writes are unchanged (data parity). Tests; docs.
