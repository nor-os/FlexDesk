## Description

`showContextMenu` (`src/ui/components/context_menu.js`, line 108) arms its outside-click listener with `document.addEventListener('mousedown', _outsideHandler, { once: true, capture: true })`. A mousedown inside the menu, for example on a separator, the menu's padding or a disabled row, triggers that listener once. The handler sees the target is inside the menu and does nothing, but `once` has already removed the listener. From then on, clicks outside leave the menu open; only Escape or choosing an item closes it. This is present in 0.17.6 and still at 0.17.18.

EcoAgent found this while moving its context menus onto FlexDesk (EcoAgent STORY-0038 and BUG-0007, `../EcoAgent/backlog/STORY-0038.md`). Its stopgap is a persistent document-level listener that calls `hideContextMenu`. EcoSim has the same exposure.

## Steps to reproduce

1. Open any `showContextMenu` menu that has a separator.
2. Press the mouse on the separator.
3. Click anywhere outside the menu, twice.

## Expected

The first outside click closes the menu, every time.

## Actual

The menu stays open until Escape.
