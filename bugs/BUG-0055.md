## Description

`mountGalleryPicker` (`src/ui/components/gallery_picker.js`, line 108) marks the chosen card with `.is-selected`, but `css/flexdesk.css` has no rule for `.twm-gallery-card.is-selected`, in 0.17.6 and still at 0.17.18. Selection works (Enter or a click records the choice), but the user can't see which card is selected. EcoAgent found this in STORY-0040 (`../EcoAgent/backlog/STORY-0040.md`), where its new-project template gallery lost the highlight its own CSS used to give. It now carries a stopgap rule.

## Steps to reproduce

1. Mount a gallery picker with two or more cards.
2. Click a card, or move to it and press Enter.

## Expected

The selected card is visibly highlighted, for example with the accent border used for focus.

## Actual

It looks the same as the others.
