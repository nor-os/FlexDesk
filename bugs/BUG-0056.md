## Description

When a saved layout names a tile type that no widget is registered for, `createWidget` returns null and `TileGrid` leaves the tile out. Nothing tells the user. The next layout save then writes the layout without that tile, so the tile, and its configuration, is gone from the user's file for good. This happens in 0.17.18.

EcoAgent STORY-0049 (`../EcoAgent/backlog/STORY-0049.md`) and EcoSim STORY-0071 (`../EcoSim/backlog/STORY-0071.md`) each carry their own `unknown_widget.js` stopgap. It draws a placeholder with `TileBase.showEmpty` that keeps the tile's saved config, so a later save keeps the tile.

## Steps to reproduce

1. Save a layout that contains a tile of type `legacy-gauge`, with no widget registered for that type.
2. Load the layout, move any other tile, and let the layout save.

## Expected

The tile shows a placeholder naming the unknown type, in its saved position. Saving keeps the tile and its config unchanged.

## Actual

The tile is missing, and after the save it is deleted from the stored layout.
