## Description

`.twm-menubar__menu` is on `--z-over-windows`. Toasts draw above that, so a toast covers an open menu bar menu and its flyouts. Context menus moved to `--z-context-menu` (10100, over toasts) in 0.17.17 (STORY-0131); menu bar menus did not.

Seen in BugDesk with the hamburger open (FlexDesk 0.17.18): the "not in a git repository" toast covered the BugDesk › Change your name… row. The bar style has the same layering.

## Steps to reproduce

1. Open a menu bar menu (bar or hamburger style) while a toast is showing over the same area.
2. The toast draws over the menu; the covered rows cannot be clicked.

## Expected

A menu bar menu draws on `--z-context-menu`, as a context menu does, over toasts and managed windows. `tests/menu_bar_css.test.mjs` §1 pins the z-index.
