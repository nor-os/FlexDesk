## Description

`css/flexdesk.css` contains 447 hex colour literals next to its tokens. Examples:
- the DataTable filter row: `.twm-data-table__filter-input` uses `background: #2a2a2a; color: #ccc; border: 1px solid #3a3a3a`, and the sticky filter cell uses `color: #ccc`;
- preview tables: `.twm-preview-table-wrap { border: 1px solid #2a2a2a }`, and its cells use `#444` and `#ddd`.

An embedder that changes a FlexDesk colour token sees most of the UI follow, but these parts keep their fixed colours. EcoAgent STORY-0059 (`../EcoAgent/backlog/STORY-0059.md`) moved all of EcoAgent's own sheets onto tokens and found that the remaining fixed colours on its landing tables come from flexdesk.css.

## Steps to reproduce

1. Load an app with a DataTable that has header filters.
2. In the CSSOM, set `--surface-1` and `--text-primary` in tokens.css to a striking colour.

## Expected

The filter inputs and preview-table borders change with the tokens.

## Actual

They keep `#2a2a2a`, `#ccc` and `#3a3a3a`.
