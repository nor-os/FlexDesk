## Description

`src/tiling/tile_breadcrumb.js` line 50 reads `ctx?.wm || window.__twm?.wm || null`. `window.__twm` is a global that an older embedder used to set; FlexDesk itself never sets it. That is the same kind of app-global read BUG-0022 removed elsewhere. EcoAgent STORY-0060 (`../EcoAgent/backlog/STORY-0060.md`) removed `window.__twm`, so for EcoAgent the fallback is dead code, and `ctx.wm` is always present. An app that happened to set a different `__twm` would have its breadcrumb navigate the wrong WM.

## Steps to reproduce

1. `git grep "__twm" src` in FlexDesk.

## Expected

The breadcrumb uses only `ctx.wm`.

## Actual

It falls back to `window.__twm?.wm`.
