## Description

Found in EcoSim on FlexDesk 0.21.0: a dashboard overlays observed 2018-26 data (at t = year - 2026, so t from -8 to 0.75) on a model run from t = 0 to 10. `buildFigure` sets `xaxis.range` to the results' first and last time, so the overlay's points before t = 0 are drawn outside the axis. Only the few points inside the run show, at its left edge; the history the overlay is there for is hidden unless the viewer presses Plotly's Autoscale.

## Steps to reproduce

1. `renderPlotGrid` with results `time: [0, 1, 2, 3]` and a series with `overlay: {...}`.
2. Pass `overlays: { [seriesId]: { years: [-8, -4.5, 0.75], values: [...] } }`.

## Expected

The x range is widened to the drawn overlays' first and last finite year: `[-8, 3]`. A hidden overlay does not widen it; an x variable instead of time still sets no range.

## Actual

`xaxis.range` is `[0, 3]`.
